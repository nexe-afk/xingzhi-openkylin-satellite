# 任务④ 星间动态云与分布式调度

## 目标
- 任务调度平均等待时间较普通调度降低 ≥10%
- 单节点故障后 60 秒内完成重新调度恢复

## 架构
- "云端全局协调 + 星间分布自治" 混合调度
- 感知：节点算力 / 负载 / 健康度
- 加权分配：健康节点优先、低负载优先、算力强优先

## 实现
- 自研轻量调度器（Python/Go）
- Docker Compose 仿真：N=4~6 星载节点 + 1 地面云节点
- 故障注入脚本：随机 kill 节点进程，计时到任务重调度执行

## 对比基线
- 普通调度：先来先服务(FCFS) / 轮询(RR)
- 优化方案：加权调度
- 同任务集、同负载

## 记录
- 调度日志 + 时间戳
- 故障注入：多次取最坏/平均恢复时间
- 大屏回放视频
