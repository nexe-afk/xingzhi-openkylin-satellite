| 框架 | 用途 | 地址 | 安装 |

| OpenKylin 3.0 | 星载OS | gitee.com/openkylin | 下载镜像 |

| Prometheus | 指标采集 | github.com/prometheus/prometheus | docker |
| Grafana | 大屏展示 | github.com/grafana/grafana | docker |
